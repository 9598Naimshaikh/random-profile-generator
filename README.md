# 🧑‍💻 Random User Profile Generator

🚀 A modern **React app** that generates random user profiles using the **RandomUser API**.  
Users can click on icons to reveal different personal details such as name, email, date of birth, phone number, address, and password.  
Built with **React**, **Axios**, and **Tailwind CSS** for a smooth and stylish experience.

## ✨ Features

- 🔁 Fetches real-time random user data from [RandomUser API](https://randomuser.me/)  
- 👤 Displays user profile with photo and personal details  
- 🖱️ Interactive icons to show details like:
  - Name  
  - Email  
  - Date of Birth  
  - Location  
  - Phone  
  - Password  
- 🎨 Modern and responsive UI built with Tailwind CSS  
- ⚡ “Generate New User” button to refresh and load new profiles  
- 💫 Loading state with smooth transitions
